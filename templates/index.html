Obelisk

A fast Open-Source Durable & Deterministic Workflow Engine

Install Get Started
1 — Install
curl -sSf https://raw.githubusercontent.com/obeli-sk/obelisk/main/download.sh | bash
2 — Write plain JavaScript
// activity: fetch weather — auto-retried on failure
export default async function get_temperature(city) {
    const resp = await fetch(`https://wttr.in/${city}?format=%t`);
    if (!resp.ok) throw `HTTP ${resp.status}`;
    return (await resp.text()).trim();
}

// workflow: fan out in parallel — crash-safe, replayable
export default function city_temperatures(cities) {
    const handles = cities.map(city => {
        const js = obelisk.createJoinSet();
        js.submit("myapp:weather/activity.get-temperature", [city]);
        return { city, js };
    });
    return handles.map(({ city, js }) => {
        const r = js.joinNext();
        return `${city}: ${obelisk.getResult(r.id).ok}`;
    }).join(", ");
}
3 — Run
obelisk server run --deployment deployment.toml

Use Web UI at :8080, Webhooks at :9090, API at :5005 or CLI to interact with the deployed application.

Why Obelisk?

JavaScript & WASM

Write activities, workflows, and webhooks in plain .js files — no build step, no bundler. Rust/Go WASM components also supported.

Crash-Resilient Workflows

Every call, sleep, and result is persisted to the execution log. Crash mid-workflow — it resumes from the last completed step on restart.

Simple Architecture

Single binary, embedded SQLite or Postgres. No brokers, no sidecars, no YAML pipelines.

Great for AI Agents

Full execution introspection via REST or CLI — fetch events, responses, child executions, logs, and source code. Hot redeploy lets agents push fixes without a server restart.
